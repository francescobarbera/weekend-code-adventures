# Scripts

The site is plain hand-written HTML served by GitHub Pages from `docs/`. There is no build step.

When you add a page or post:

1. Copy the `<head>` block of an existing page and update the `<title>`, `meta description`, `canonical`, `og:*`/`twitter:*` tags. Posts also need `<meta property="article:published_time" content="YYYY-MM-DD" />`. That date is what puts a page in the feed.
2. Regenerate the Atom feed (`docs/feed.xml`) and the sitemap (`docs/sitemap.xml`):

   ```sh
   python3 scripts/generate_feed_and_sitemap.py
   ```

   (Python 3 standard library only.) Commit the regenerated files.

The default social image `docs/og-image.png` (1200x630) is generated by `python3 scripts/make_og_image.py` (needs Pillow).
